JAN-120

Drift læringssløyfen for Wax og Sasa

Run the learning loop for Wax and Sasa

Oppgave → demonstrasjon → guidet forsøk → selvstendig forsøk → review → evidens i People Brain.

Task → demonstration → guided attempt → independent attempt → review → evidence in People Brain.

SenereLaterDepends on: JON-006, JAN-002
  • Velg én ekte, lavrisiko oppgave fra Smokefree.
  • Vis én gang og forklar kvalitetskriteriet.
  • La personen utføre med veiledning, deretter alene.
  • Review resultatet mot kriteriet—ikke mot personlighet.
  • Registrer demonstrert kompetanse og neste læringssteg.
  • Select one real, low-risk Smokefree task.
  • Demonstrate once and explain the quality criterion.
  • Have the person perform with guidance, then independently.
  • Review the result against criteria—not personality.
  • Record demonstrated competence and the next learning step.
Ferdig når: Minst én oppgave har to arbeidsprøver og et eksplisitt kompetanseresultat.
Done when: At least one task has two work samples and an explicit competence result.
JAN-110

Lag en reell kompetansebaseline for Wax og Sasa

Create a real capability baseline for Wax and Sasa

Ikke bruk de hypotetiske ferdighetstallene. Mål kun det hver person faktisk demonstrerer gjennom små, trygge arbeidsprøver basert på behovene i Case #001.

Do not use hypothetical skill scores. Measure only what each person demonstrates through small, safe work samples based on Case #001 needs.

BlokkertBlockedDepends on: PAT-101, JON-006
  • Hent de faktiske capability-behovene fra system- og problemkartet.
  • Lag én lavrisiko sandbox-/read-only-prøve per capability.
  • Bruk samme tydelige kvalitetskriterium for begge.
  • Registrer utført selvstendig, utført med hjelp eller ikke demonstrert—aldri antatt.
  • La Wax og Sasa lese og korrigere registreringen.
  • Take actual capability needs from the system and problem map.
  • Create one low-risk sandbox/read-only sample per capability.
  • Use the same explicit quality criterion for both.
  • Record independent, assisted or not demonstrated—never assumed.
  • Let Wax and Sasa read and correct the record.
Ferdig når: People Brain viser kilde, arbeidsprøve, resultat og neste steg for hver vurdert capability.
Done when: People Brain shows source, work sample, result and next step for each assessed capability.
JAN-111

Før lærings- og kunnskapshull-loggen

Maintain the learning and knowledge-gap log

AI-en skal lære hvilke tiltak som gir bedre resultat på ulike oppgaver—ikke lage personlighetstyper. Når noen trenger hjelp, forbedres både personens plan og selve trainee-programmet.

The AI learns which interventions improve results on different tasks—not personality types. When someone needs help, both the person's plan and the trainee programme improve.

BlokkertBlockedDepends on: JAN-110, JAN-120
  • For hvert forsøk: registrer oppgave, undervisningsformat, hjelp, feil, kvalitet og tid.
  • Sammenlign guidet og selvstendig resultat før du endrer læringsplanen.
  • Når samme spørsmål gjentas: oppdater SOP/knowledge base eller lag mikroøvelse.
  • Registrer kun observerbar læringsevidens og gi personen innsyn.
  • For each attempt record task, teaching format, help, errors, quality and time.
  • Compare guided and independent outcomes before adapting the plan.
  • When a question repeats, update the SOP/knowledge base or create a micro-exercise.
  • Store only observable learning evidence and give the person visibility.
Ferdig når: Minst ett kunnskapshull har gitt en konkret programforbedring og et målbart nytt forsøk.
Done when: At least one knowledge gap has produced a programme improvement and a measured new attempt.
